# Pong Game

A simple browser-based Pong game built with HTML, CSS, and JavaScript.

## How to Play

- Move the left paddle with your mouse or the Up/Down arrow keys.
- The right paddle is controlled by the computer.
- Bounce the ball past the computer paddle to score.
- The game tracks the score for both players.

## Run It Locally

Open `index.html` in a browser.

This project is suitable for GitHub Pages and can be served directly from the repository root.
